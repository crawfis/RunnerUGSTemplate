“A contract that references the game's types is not a contract.”

  • Payloads are declared only where the type is primitive and unambiguous
  • The difficulty payload is deliberately undeclared — today it carries a game-side config type
  • The balance crosses as a long, not the service's update type — unwrapped by hand; a pair forwards a payload untouched
// the services' side of the seam
private void OnCurrencyBalanceChanged(
    string n, object s, object data)
{
    // The UGS payload is a type in this package. Forwarding
    // it would hand a game a services type to cast — the
    // coupling this bridge exists to prevent.
    if (data is CurrencyBalanceUpdate update)
        BalanceChanged.Publish(this, update.Balance);
        // only the number crosses
}
Three values, not a bool ServicesStatus is Connecting / Ready / Unavailable, because “not ready” is two different situations to a player: still trying, and gave up. A loading screen that can't tell them apart shows the same spinner for a slow connection and a dead one.
THE RULE, stated once: the contract may name primitives and its own two types (the enum and ServicesStatus). It may not name a type from either side. The moment it does, one side can no longer be replaced without the other recompiling. The code is condensed from the real handler — comments shortened, one attribute dropped. The behavior is exact: the services' payload type is unwrapped and only the long crosses. IF ASKED “why not an interface and dependency injection?” — the appendix Q&A has the full answer. Short form: an interface is still a compile-time reference from one side to a type; an enum in a third package plus events-as-data is what buys the logger, the domain listing and the audit.

  • Chains are a flat list of pairs, not a dictionary, so one source may declare several consequences. Targets fire synchronously, in declaration order.
  • All eight dispatch classes — three auto-flows, five bridges — share one implementation in the common package. A two-way bridge holds two dispatchers.
War story — the dictionary ceiling This used to be a dictionary: one successor per event. “That ceiling did not produce bugs directly — it produced workarounds. A developer who found a source event's slot already taken published the second consequence by hand inside a controller instead, which is how failure logic came to publish pause events.”
THE LESSON, and the best line in the act: when the sanctioned path has a ceiling, people don't stop — they route around it, and the workaround is exactly where the coupling leaks back in. Mention that /audit-events checks these tables for cycles, since chains fire synchronously — a cycle is an infinite loop, not a slow frame.

Q&A cheat sheet

If they ask…Say
Why an enum contract, not an interface and dependency injection?An interface is still a compile-time reference to a type someone owns. Ten enum members in a third package are owned by neither — and events-as-data is what buys the logger, List Domains, the chain tables and the audit.
Isn't retained delivery just a global variable?A last-value cache per event, replayed on subscribe — used only for values that stay true (7 of 271). The Upgrade Audit reports which events actually had a late subscriber: evidence first, then upgrade.
Why assembly definitions here and none in the sibling?The sibling is one assembly for onboarding speed. Here the services arrive as packages, so the boundary comes free — and game-to-UGS not compiling is worth the reference edits.
Why is the services code read-only in the game repo?Resolved by git URL so it can sit under a different game unchanged. To edit it: copy it into Assets, embed it, or fork it — task Q2 walks all three, and CC0 means you may.
Does the AI break the architecture?Yes, the same ways juniors do — automating past a gate, duplicating an event, forgetting OnDestroy. So the rules live in files the agent must read, and the audit runs before merge.
Five questions that come up every time. Put the slide up while you answer — it buys thinking time and reads as preparation rather than defensiveness. For “performance of all that indirection”: events fire on state transitions, not per frame — the hottest is the distance tick. Dispatch is synchronous, no reflection at publish. It has not been a bottleneck; profile before believing anyone, including me.
